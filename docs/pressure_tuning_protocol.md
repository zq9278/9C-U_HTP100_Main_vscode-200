# 压力调参协议

调参工具与实际屏幕共用 USART2，固定为 115200 8N1。调参协议使用 `7A A7`，屏幕协议继续使用 `5A A5` 和 `6A A6`。

## 帧格式

| 字段 | 长度 | 说明 |
|---|---:|---|
| 帧头 | 2 | `7A A7` |
| 版本 | 1 | 当前为 `01` |
| 命令 | 1 | 命令字 |
| 序号 | 1 | 0～255 |
| 负载长度 | 1 | 0～64 |
| 负载 | N | 小端格式 |
| CRC16 | 2 | Modbus CRC16，小端；覆盖帧头至负载末尾 |
| 帧尾 | 2 | `0D 0A` |

## 命令

| 命令 | 方向 | 用途 |
|---:|---|---|
| `01` | 上位机→主板 | 握手 |
| `10` / `11` | 上位机→主板 | 读取全部/单挡 RAM 参数 |
| `12` | 上位机→主板 | 兼容旧上位机：整挡写入 RAM |
| `13` | 上位机→主板 | 将当前五挡 RAM 参数保存到外置 EEPROM |
| `14` | 上位机→主板 | RAM 恢复程序内置默认值 |
| `15` | 上位机→主板 | 单字段即时写入 RAM |
| `20` / `21` | 上位机→主板 | 设置目标/准备压力模式 |
| `22` / `23` | 上位机→主板 | 开始/停止并回零 |
| `24` / `25` | 上位机→主板 | 遥测周期控制/读取一次状态 |
| `26` / `27` | 上位机→主板 | 读取/设置温控 PID RAM 参数 |
| `28` / `29` | 上位机→主板 | 设置温度目标/准备纯加热模式 |
| `30` | 上位机→主板 | 测试调试模式开关，负载 `00/01` |
| `81` | 主板→上位机 | 固件与协议信息 |
| `90` | 主板→上位机 | 单挡参数 |
| `91` | 主板→上位机 | 命令应答 |
| `92` | 主板→上位机 | 温控 PID 参数 |
| `A0` | 主板→上位机 | 压力、温度及设备状态遥测 |
| `A1` | 主板→上位机 | 回零完成事件 |

## RAM 调参与外置存储

上位机修改表格后，通过 `0x15` 短帧将该单元格写入 RAM，并立即影响后续控制。执行“同步整表并保存”时，上位机先用 5 条 `0x12` 完整档位命令原子更新当前五挡表格，确认所有应答成功后才发送 `0x13`；主板随后将完整五挡 RAM 配置保存到板载外置 EEPROM。导入 JSON 本身只更新上位机表格，不直接改动设备。主板上电时校验存储版本、字段范围和 CRC；校验成功则加载外置配置，否则使用程序编译时默认值。

存储记录位于外置 EEPROM `0x20～0x93`，使用定点编码、版本号和 CRC16。保存时先使旧记录失效，写完数据后最后提交魔数，并执行完整回读比较，避免掉电留下被误认为有效的半写记录。完整写入约需 0.7 秒，因此保存只允许在待机或已安全关闭全部输出的故障状态执行，恢复默认值仍只允许在待机状态执行，避免阻塞加热、压力控制或回零。

`0x15` 的 6 字节负载为：挡位索引 1 字节、字段索引 1 字节、float32 小端数值 4 字节。字段顺序是：灵敏度、偏移量、快速速度、接近速度、回退速度、接近阈值、保压阈值、保压时间、回退时间、Kp、Ki。

`0x27` 和 `0x92` 的 12 字节负载均为三个小端 `float32`，顺序为温控 `Kp`、`Ki`、`Kd`。默认值为 `30 / 5 / 5`，允许范围为 `Kp 0～100`、`Ki 0～50`、`Kd 0～20`；原始积分累计值限制为 `-20～+20 °C·s`，实际积分输出 `Ki × 积分` 限制为 `-40～+40 PWM`。设置成功后立即清空温控积分与微分历史，只在 RAM 中生效。`0x28` 的 4 字节负载为目标温度 `float32`，范围 `20.0～<44.0 °C`；`0x29` 无负载。`0x10` 读取全部参数时会在五挡压力参数之后额外返回一个 `0x92` 帧。

`0xA0` 当前使用 53 字节负载。原 36 字节布局保持不变，偏移 36 起依次追加当前控制目标温度 `float32`、实测温度 `float32`、实测温度有效标志 `uint8`、加热功率百分比 `float32`、温控积分输出 `float32`。温度单位为 °C，功率范围为 `0～100%`；积分输出为 `Ki × ∫(目标温度 - 实测温度)dt`，单位与 PWM 比较值相同。预热阶段目标温度为预热设定值。加热或自动模式复用控制回路的最新温度，纯压力模式通过无副作用的遥测读取取得温度，不会启动加热或改变眼盾插拔消抖状态。上位机仍兼容 27/36/45 字节旧遥测帧。

## 调试模式

调试模式只在 RAM 中有效。开启后充电不关闭屏幕，并临时绕过充电治疗联锁。上位机每 5 秒发送一次保活；主控连续 15 秒收不到调参命令会退出调试模式，并安全停止正在进行的治疗。

## 串口应答注意事项

主板收到命令后先执行，再发送 `0x91` ACK。因此“未收到 ACK”不能直接等同于命令未执行。上位机会优先读取串口缓冲区，并尝试用 `0xA0` 遥测状态确认准备、开始和停止命令；如果本次发送后完全没有收到主板数据，应检查 `PA2/USART2_TX → USB 串口 RX` 和共地。调试时不要把两个 TX 输出直接并联到 MCU 的 RX。
