# HTP100 压力标定、PID 调参与老化工具

串口固定为 115200、8N1，使用主板 USART2（PA2/PA3）。

- 调参协议帧头：`7A A7`，当前协议版本为 `8`
- 实际屏幕工作协议帧头：`5A A5`
- 实际屏幕准备/设置协议帧头：`6A A6`

三种帧头互不相同，固件会在同一 USART2 接收流中分别解析。TTL 电气层仍只能有一个 TX 主机主动驱动 MCU RX；若实际屏幕 TX 与 USB 串口 TX 直接并联，调参时必须避免两端同时发送或增加隔离/复用电路。

## 压力调参

1. 连接串口，读取设备五挡参数。
2. 勾选“单元格修改后即时写入 RAM”（默认已勾选）。
3. 修改灵敏度、偏移量、速度、每挡回退时间、快慢切换百分比、PID 切换百分比或 PID；停止编辑约 300 ms 后，该单元格会通过 `0x15` 短帧写入主控 RAM。PID 切换百分比不能小于快慢切换百分比。
4. 用“准备压力”“开始压力治疗”和“停止并回零”验证效果。
5. 参数确认后点击“同步整表并保存到外置 EEPROM”。上位机会先逐项同步当前表格的五挡参数，全部应答成功后才发送 EEPROM 保存命令；保存成功后 MCU 重启仍然有效。也可以导出 JSON 留档。

压力控制循环固定为“快速前进 → 慢速前进 → PID 保压 → 回退 → 下一轮”。例如目标 350 mmHg、快慢切换 65%、PID 切换 70% 时：低于 227.5 mmHg 快速前进；达到 227.5 mmHg 后切换为慢速前进；达到 245 mmHg 后进入 PID 控制。进入 PID 状态时不立即计时，只有实际压力第一次达到目标 350 mmHg 时才开始固定 1000 ms 的保压计时，计时结束后立即回退。五挡回退时间默认依次为 500、600、800、800、1000 ms，每挡均可在上位机独立修改；回退计时结束后开始下一轮。五挡慢速速度默认依次为 6000、9000、9000、9000、9000，仍可在上位机修改。

稳压采用滤波后的压力和实际控制周期计算 PI，并带 ±3 mmHg 死区、积分输出限幅、抗积分饱和、闭环速度限幅和速度斜率限制。默认 Ki 为 0，建议先只调 Kp；到达目标时的剩余前进速度、±3 mmHg 死区边界和最小控制速度可能共同造成目标附近的正反向极限振荡。压力曲线旁实时显示电机速度指令和压力误差，便于判断振荡究竟来自压力噪声还是电机反复换向。

实时遥测默认每 50 ms 更新，同时显示压力和温度，格式均为“实测 / 设定”。加热或自动模式复用控制回路的最新温度，纯压力模式会额外只读温度传感器而不会启动加热。眼盾温度传感器不可用时显示“传感器暂不可用”；连接未提供温度遥测的旧固件时显示“旧固件未提供”。

## 温控 PID 调参

上位机提供目标温度、`Kp`、`Ki`、`Kd` 控件，以及读取、应用、准备并开始温控、停止并回零按钮。PID 默认值为 `30.0 / 5.0 / 5.0`，允许范围依次为 `0～100 / 0～50 / 0～20`；原始积分累计值限制为 `-20～+20 °C·s`，实际积分输出 `Ki × 积分` 进一步限制为 `-40～+40 PWM`。参数通过 `0x27` 写入主控 RAM，写入时会清空积分和微分历史；重启 MCU 后恢复程序默认值，不写入外置 EEPROM。

温度曲线保存最近 600 个有效遥测点：左轴绘制实测温度和控制目标，右轴同时绘制加热功率百分比和温控积分输出百分比。积分输出为 `Ki × ∫(目标温度 - 实测温度)dt`，曲线按 PWM 满量程换算为百分比，右轴会保留负区间；实时状态区同时显示积分输出的 PWM 值和百分比。点击“准备并开始温控”会依次写入目标与 PID、准备加热并开始治疗，需要有效眼盾，并遵循现有眼盾消耗与安全联锁规则。

导入 JSON 只负责把参数载入上位机表格和温控 PID 控件，不会在导入瞬间改动设备。导入后点击“同步整表并保存到外置 EEPROM”写入压力参数；温控 PID 需点击“应用温控 PID”写入 RAM。

主控上电时优先加载通过版本、范围和 CRC 校验的外置 EEPROM 配置；存储空白或损坏时使用程序内置默认值。本版 EEPROM 压力参数版本升级为 8，旧配置会自动失效并加载新默认值；快慢切换和 PID 切换均可按目标值百分比调节，五挡回退时间可独立调节，保压时间固定为 1000 ms。“恢复程序默认值”只恢复 RAM，如需覆盖外置配置，需要再点击“同步整表并保存到外置 EEPROM”。JSON 配置格式也升级为 `HTP100-pressure-profile-v8`，旧格式会拒绝导入。

## ACK 超时

命令可能已经执行，但主控到上位机的 ACK 没有到达。新版工具会显示“执行结果未知”，并用实时遥测确认准备、开始、停止状态。若实时压力、状态和 ADC 原始值也不更新，请检查：

- MCU `PA2/USART2_TX` 是否接到 USB 串口模块 `RX`
- USB 串口模块 `TX` 是否接到 MCU `PA3/USART2_RX`
- 两端是否共地

执行结果未知时不要连续重复点击，尤其不要重复发送开始命令。

## 调试与自动老化

“进入调试模式”是测试专用开关：充电时保持屏幕供电，并临时允许治疗。上位机每 5 秒保活，主控 15 秒收不到调参命令会自动退出并停止当前治疗。

自动老化使用真实屏幕协议依次发送 `0x1037` 自动预热、`0x1036` 自动治疗、按设定前进时间运行、`0x1038` 停止。随后必须在设定后退等待时间内收到主控 `7A A7 / A1` 回零完成事件。前进时间和后退等待时间默认均为 5 秒，可在界面修改；前进期间最高压力需达到目标压力减 25 mmHg，否则记录失败并发送钉钉通知。

累计轮回统计保存在 `%LOCALAPPDATA%\HTP100_Pressure_Tuning_Host\aging_stats.json`，逐轮文本记录保存在同目录的 `aging_cycles.txt`。

顶部“字体”和“界面”可分别调整字体大小和整体布局缩放。有效受力面积按实测 `84.8 mm²` 计算：`力(N) = 压力(mmHg) × 133.322 × 84.8×10⁻⁶`，例如 350 mmHg 约为 3.957 N。
